# 端侧屏幕布局设计（7 寸 1024×600 → A5 打印）

> 适用范围：边缘设备 (`edge/debian/fancy-print-ui`、`edge/android/app`) 上「拍照预览 → 保存 / 打印 / 语音」主交互页。
>
> 设计目标：
> 1. 屏幕显示的照片 **完整、不被裁切、不留黑边**。
> 2. 打印到 A5 纸时 **充分铺满**，所见即所得。
> 3. 触控按钮足够大，小孩与家长都能轻松点中。

---

## 0. 目标硬件（实测）

| 项目 | 值 |
|---|---|
| 设备型号 | rk3568_u（Rockchip RK3568） |
| Android 版本 | 14（SDK 34） |
| 屏幕分辨率 | **1024 × 600 px**（物理像素，横屏固定） |
| 物理 DPI | 213 dpi |
| 出厂 density | **320 dpi（scale=2.0）** |

**关键约束**：出厂 density 为 320（1dp = 2px）。布局 XML 中的 dp 值须按 **目标像素 ÷ 2** 计算。例如控制栏宽度目标 232px → 布局写 `116dp`（232 ÷ 2）。运行时 dp × 2 = 目标像素。

> 若未来硬件改为 160dpi 屏幕，只需将所有 layout dp 值翻倍即可恢复设计比例。

所有尺寸单位约定：
- 本文档中"设计 px" = 160dpi 环境下 1dp 的等效值（即**不缩放的绝对像素尺寸**）。
- 布局 XML 中的 dp = 设计 px ÷ 2（因为 320dpi 下 dp × 2 = px）。

| 设计 px (doc) | 布局 dp (320dpi) | 渲染 px (320dpi) |
|---|---|---|
| 40（状态栏高度）| 20dp | 40px |
| 232（控制栏宽度）| 116dp | 232px |
| 792（照片区宽度）| 396dp | 792px |
| 560（主内容区）| 280dp | 560px |

## 1. 核心约束

| 介质 | 尺寸 | 长宽比 |
|---|---|---|
| 屏幕 | 1024 × 600 px | 1.707 : 1 |
| A5 横向 | 210 × 148 mm | **1.419 : 1** (≈ √2) |
| A5 纵向 | 148 × 210 mm | 1 : 1.419 |

**关键决策：** 屏幕比 A5 横向更宽，因此

- 照片显示区按 **A5 横向比例** 占满主内容区高度；
- 屏幕右侧多出的宽度正好作为按钮控制栏；
- 这样照片不被裁切、不留黑边、打印时直接铺满 A5。

## 2. 尺寸预算

| 区域 | 尺寸 | 说明 |
|---|---|---|
| 顶部状态栏 | 1024 × **40 px** | 全局信息常驻，推荐 36–48 之间 |
| 主内容区 | 1024 × **560 px** | 600 − 40 |
| └ 照片区 | **792 × 560 px** | 560 × √2 ≈ 792，A5 横向 √2:1 |
| └ 控制栏 | **232 × 560 px** | 1024 − 792 |

按钮排布（控制栏 232 × 560）：
- 3 个按钮纵向均分，每个 **176 × 140 px**
- 按钮间距 24 px，控制栏左右内边距各 28 px，上下内边距各 24 px
- 实际占用：176×3 + 24×2 = 516 px，竖向余量 44 px 可微调放大

## 4. 顶部状态栏内容规范

状态栏 **只承载全局且持续可见** 的信息，不放可点击的操作按钮（避免误触），交互一律下放到右侧控制栏。

| 位置 | 元素 | 用途 |
|---|---|---|
| 左 1 | 打印机状态徽标 + 文字 | `就绪 / 缺纸 / 缺墨 / 打印中…` —— 最关键，一眼可见 |
| 左 2 | 网络 / MQTT 连接 | Wi‑Fi 信号或离线图标 |
| 左 3 | 电量（若电池供电） | 百分比 + 充电状态 |
| 中 / 右 1 | 当前任务进度（可选） | 上传 / 合成进度，无任务时隐藏 |
| 右 1 | 时间 | HH:mm |
| 右 2 | 设置入口 ⚙ | 进入家长设置 / 设备绑定（唯一例外，可点击） |

## 5. 右侧按钮规范

| 按钮 | 类型 | 触发方式 | 说明 |
|---|---|---|---|
| 保存 | 次要 | 点击 | 将当前预览图存入本地相册 / 上云 |
| 打印 | 次要 | 点击 | 调用打印队列，按 A5 横向铺满输出 |
| 按住说话 | **主操作** | **长按 (push‑to‑talk)** | 录音 + 上行语音识别，松开停止 |

- 三按钮 **等宽 176 px**，垂直对齐；
- 「按住说话」可加底色/麦克风图标，作为视觉重点；
- 所有按钮触控目标 ≥ 140 px，远超 Material 48 dp 与 HIG 44 pt 最小值，戴手套或儿童也可点准。

## 6. 照片源与打印对齐

| 项 | 要求 |
|---|---|
| 照片宽高比 | **必须** = √2 : 1（≈ 1.4142）—— 拍照 / 导入时即按此比例裁剪 |
| 照片分辨率 | ≥ **2480 × 1754 px**（300 DPI × A5 横向），低于此值需提示用户 |
| 屏幕预览裁剪框 | 与最终打印输出 **共用同一坐标系**，避免「屏幕看到的 ≠ 打印出来的」 |
| 打印设置 | 启用 **无边距 / borderless**，或将页面边距统一设为 0–3 mm |
| 纸张方向 | A5 **横向** (landscape)，与屏幕预览方向一致 |

## 7. 实现骨架（参考）

本项目端侧 UI 存在两套实现，需保持视觉与交互一致：

- **Debian kiosk**：`edge/debian/fancy-print-ui`，React 18 + TypeScript + Vite，原生 CSS（无 Tailwind），className 约定见 `src/index.css`。
- **Android**：`edge/android/app`，原生 Android Java + XML 布局，资源位于 `app/src/main/res/layout/`。

两端**核心约束完全一致**：照片区按 √2 : 1 占满主区高度，右栏固定 232 px，顶栏固定 40 px。

### 7.1 Debian — React + TypeScript

```tsx
// edge/debian/fancy-print-ui/src/pages/PreviewPage.tsx (布局骨架)
export const PreviewPage: React.FC<Props> = ({ imageUrl }) => (
  <div className="app-container">
    {/* ① 顶部状态栏：高度 40px，由 CSS 固定 */}
    <header className="top-bar">
      <PrinterStatusBadge />     {/* 就绪 / 缺纸 / 打印中… */}
      <WifiIndicator />
      <BatteryIndicator />
      <span className="top-bar-spacer" />
      <ClockHHmm />
      <SettingsEntry />          {/* 唯一可点击元素 */}
    </header>

    {/* ② 主内容区：flex:1 自适应剩余 560px */}
    <main className="main-content">
      {/* 左：照片区，AspectRatio 锁 √2:1 */}
      <section className="preview-area">
        <div className="preview-frame a5-landscape">
          {imageUrl && <img src={imageUrl} alt="A5 预览" className="preview-image" />}
        </div>
      </section>

      {/* 右：固定 232px 控制栏 */}
      <aside className="toolbar">
        <BigButton icon="save"  label="保存" onClick={onSave} />
        <BigButton icon="print" label="打印" onClick={onPrint} />
        <BigButton icon="mic"   label="按住说话" primary holdToTalk onHold={onTalk} />
      </aside>
    </main>
  </div>
);
```

配套 CSS（追加到 `src/index.css`）：

```css
/* ---------- 主布局骨架 ---------- */
.app-container   { display: flex; flex-direction: column; width: 1024px; height: 600px; }
.top-bar         { flex: 0 0 40px;  display: flex; align-items: center; padding: 0 16px; gap: 12px; }
.main-content    { flex: 1 1 auto;  display: flex; min-height: 0; }

/* ---------- 照片区：√2:1 ---------- */
.preview-area    { flex: 1 1 auto;  display: flex; align-items: center; justify-content: center; min-width: 0; }
.preview-frame.a5-landscape {
  aspect-ratio: 1.4142 / 1;        /* 关键：A5 横向比 */
  height: 100%;                    /* 占满主区高度 → 自动得到 792×560 */
  max-width: 100%;
  overflow: hidden;
}
.preview-image   { width: 100%; height: 100%; object-fit: cover; display: block; }

/* ---------- 右控制栏：固定 232px ---------- */
.toolbar {
  flex: 0 0 232px;
  display: flex; flex-direction: column; justify-content: space-between;
  padding: 24px 28px;
  gap: 24px;
}
.big-button      { width: 176px; height: 140px; border-radius: 16px; font-size: 22px; }
.big-button.primary { background: var(--accent); }
```

要点：
- `aspect-ratio: 1.4142 / 1` + `height:100%` 是浏览器原生约束，等价于 Android XML 的固定宽高比 View，比手算尺寸更稳。
- `.toolbar` 用 `flex: 0 0 232px` 锁宽，避免照片区在不同 DPR 下挤占按钮。
- `BigButton` 的 `holdToTalk` 用 `onPointerDown / onPointerUp / onPointerCancel` 实现，覆盖鼠标 + 触摸 + 笔三种输入。

### 7.2 Android — Java + XML 布局

> **密度要求**：设备必须运行在 **160dpi** 才能使 dp = px。
> 出厂 density 为 320，详见 §0。
> 下面代码中的 dp 值在 160dpi 下与本文档的 px 值一一对应。

```xml
<!-- edge/android/app/src/main/res/layout/activity_print_confirm.xml (布局骨架) -->
<androidx.constraintlayout.widget.ConstraintLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <!-- ① 顶部状态栏：40dp = 40px @160dpi -->
    <include
        android:id="@+id/top_bar"
        layout="@layout/view_top_status_bar"
        android:layout_width="0dp"
        android:layout_height="40dp"
        app:layout_constraintTop_toTopOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintEnd_toEndOf="parent" />

    <!-- ② 右控制栏：固定 232dp = 232px @160dpi -->
    <LinearLayout
        android:id="@+id/toolbar"
        android:layout_width="232dp"
        android:layout_height="0dp"
        android:orientation="vertical"
        android:padding="24dp"
        android:gravity="center"
        app:layout_constraintTop_toBottomOf="@id/top_bar"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintEnd_toEndOf="parent">

        <Button android:id="@+id/btn_save"  style="@style/BigButton" android:text="保存" />
        <Space android:layout_width="match_parent" android:layout_height="24dp" />
        <Button android:id="@+id/btn_print" style="@style/BigButton" android:text="打印" />
        <Space android:layout_width="match_parent" android:layout_height="24dp" />
        <Button android:id="@+id/btn_talk"  style="@style/BigButton.Primary" android:text="按住说话" />
    </LinearLayout>

    <!-- ③ 照片区：792 × 560 @160dpi -->
    <FrameLayout
        android:id="@+id/preview_area"
        android:layout_width="0dp"
        android:layout_height="0dp"
        app:layout_constraintDimensionRatio="H,1.4142:1"
        app:layout_constraintTop_toBottomOf="@id/top_bar"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintEnd_toStartOf="@id/toolbar">

        <ImageView
            android:id="@+id/iv_preview"
            android:layout_width="match_parent"
            android:layout_height="match_parent"
            android:scaleType="centerCrop"
            android:contentDescription="A5 预览" />
    </FrameLayout>

</androidx.constraintlayout.widget.ConstraintLayout>
```

配套 `styles.xml`：

```xml
<style name="BigButton" parent="Widget.MaterialComponents.Button">
    <item name="android:layout_width">176dp</item>
    <item name="android:layout_height">140dp</item>
    <item name="android:textSize">22sp</item>
    <item name="cornerRadius">16dp</item>
</style>
<style name="BigButton.Primary">
    <item name="backgroundTint">@color/accent</item>
</style>
```

要点：
- 所有 dp 值在 160dpi 下直接对应物理像素，无需在代码中做密度换算。
- `app:layout_constraintDimensionRatio="H,1.4142:1"` 是 ConstraintLayout 锁宽高比的原生写法，等价于 CSS 的 `aspect-ratio`，比硬编码 792dp 更鲁棒。
- 「按住说话」用 `View.OnTouchListener` 监听 `ACTION_DOWN / ACTION_UP / ACTION_CANCEL`，分别对应 `AudioController.startRecord()` / `stopRecord()`（参见 `audio/AudioController.java`）。
- 顶栏抽成独立 `view_top_status_bar.xml` 用 `<include>` 引入，所有页面复用同一份。

## 8. 屏幕尺寸适配回退

若后续硬件升级到不同分辨率，仅需保留两条不变量：

1. **照片区** 始终用 `aspect-ratio: 1.4142/1`（CSS）或 `constraintDimensionRatio="H,1.4142:1"`（Android）占满主内容高度；
2. **控制栏宽度** = 屏幕宽 − 照片宽，再约束最小值（建议 ≥ 200 px / dp）。

Android 端需同步调整 **density**，使 dp 值适配新分辨率：

| 屏幕 | 状态栏 | 照片区 | 控制栏 | 建议 density |
|---|---|---|---|---|
| 1024 × 600 | 40 | 792 × 560 | 232 × 560 | **320**（dp = px ÷ 2） |
| 1280 × 800 | 48 | 1063 × 752 | 217 × 752 | 200（保持物理尺寸一致）|
| 1920 × 1080 | 56 | 1448 × 1024 | 472 × 1024 | 240（保持物理尺寸一致）|

控制栏过宽时（如 1920×1080），可改为「按钮 + 缩略图历史栏」双列以更好利用空间。
